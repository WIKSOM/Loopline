How to use Loopline

Welcome Website Notice

This website was created as a new group chat after the war with the teachers kept getting group chats removed. The goal is to provide a place where everyone can chat without it constantly being shut down. Please use this website as our group chat, but keep in mind that there are a few limitations:

  • Limited storage is available.
  • Some features are still being developed.
  • This is a work in progress, there will be updates.
  • Bugs are very common.

Important: Do not share this website with anyone outside of our group. Keeping it private helps ensure it stays available for everyone.
